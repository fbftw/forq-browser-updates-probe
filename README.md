# FORQ Browser – Probe der Updateverteilung

**Nicht zur Installation.** Dieses Repository dient nur Prüfläufen der Updateverteilung über GitHub-Releases.

- Die Releases hier sind mit einem **Testschlüssel** signiert. Ein normal installierter FORQ Browser nimmt sie nicht an; er vertraut nur dem Freigabeschlüssel der FORQ-Familie.
- Die echten Fassungen stehen unter [fbftw/forq-browser-updates](https://github.com/fbftw/forq-browser-updates/releases/latest).
